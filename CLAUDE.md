# CLAUDE.md

This file provides guidance for Claude Code when working in this repository.

## Project

godot-correctness-mcp -- Offline static correctness MCP server for Godot 4.x GDScript projects

**Version:** see `package.json`
**License:** CC-BY-NC-ND-4.0
**Author:** TMHSDigital

## Key paths

- Source: `src/` (TypeScript)
- MCP tools: `src/tools/` (registered with `server.registerTool`; shared `ok`/`fail`/`guard` in `src/tools/result.ts`)
- Lint engine and rules: `src/lint/`, `src/lint/rules/`
- Scene / project / registry checks: `src/scenes/`
- API symbol DB lookup and diff: `src/symbols/` (data in `data/`)
- CLI: `src/cli.ts` (`gdcorrect`)
- Package manifest: `package.json` (version source of truth)
- Tool list: `mcp-tools.json` (generated by `npm run generate:tools`)
- Docs site: `docs/`
- CI workflows: `.github/workflows/`

## Conventions

- Use conventional commits (`feat:`, `fix:`, `chore:`, `docs:`)
- Work directly on `main` (no PRs or feature branches). Bump the version in `package.json` with `npm version <patch|minor|major> --no-git-tag-version` (keeps the lockfile in sync); `release.yml` tags the new version once CI passes on main and dispatches `publish.yml`, which publishes it to npm via trusted publishing (OIDC, no token)
- Run `npm run generate:tools` after changing any tool; a test fails if `mcp-tools.json` drifts

## Testing

```bash
npm run build
npm test
npm run typecheck
npm run lint
```
